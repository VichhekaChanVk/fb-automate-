Data Deletion Instructions

App: VichhekaCat (fb-automate)

VichhekaCat stores data only on the computer of the person running it. It keeps no data on any server, so deletion is done locally and in your Facebook settings.

1. Remove the app's access on Facebook

  1. Open Facebook and go to Settings & privacy → Settings.
  2. Open Business integrations (or Apps and websites).
  3. Find VichhekaCat and click Remove.

This immediately revokes every access token the app was given.

2. Delete local data

  1. In the app dashboard, click remove next to each Page, or
  2. Close the app and delete the file fb_scheduler/posts.db. This erases all stored tokens, Page names, and post history.
